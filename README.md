# TamNDK Revit Releases

This repository contains official TamNDK installer files and release notes. Source code is maintained separately.

## Install

1. Open [Releases](../../releases).
2. Download the latest `TamNDK-Setup-x.y.z.exe`.
3. Close Autodesk Revit, then run the installer.
4. Open Revit 2024 and sign in once with the account issued by your administrator.

## Verify a download

Every installer release includes a `.sha256` file. Compare it with the installer before deploying at your office.

## Support

TamNDK currently targets Autodesk Revit 2024. Contact the TamNDK administrator for a license or support.
